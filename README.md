# Автокликер для Windows

Небольшая утилита: шлёт клики мышью через Win32 `SendInput`. Работает в двух режимах —
с окном и индикатором состояния и как консольная программа. Один файл, без установки и
без зависимостей.

## Скачивание

В [Releases](../../releases) лежит `autoclicker.exe` — самодостаточный файл, .NET на машине
не нужен. Windows может предупредить, что файл из интернета: «Свойства → Разблокировать».

## Возможности

| | |
|---|---|
| Интервал | от 10 мс до 60 с |
| Кнопка | левая, правая, средняя |
| Куда кликает | туда, где курсор, или в запомненную точку |
| Лимит | сколько кликов сделать, по умолчанию без лимита |
| Индикатор | зелёная/серая лампа в окне, заголовок и значок в трее |
| При старте | окно сворачивается, чтобы клики не попали в него; клик по значку — вернуть |
| Клавиша старт/стоп | на выбор: `Ctrl+Alt+F3`, `Ctrl+Alt+Space`, `Ctrl+Shift+F3`, `Alt+Insert` — выбор сохраняется |
| Без клавиш | меню значка в трее: старт/стоп, взять позицию курсора, выход |
| Один запуск | второе окно не стартует, чтобы не спорить из-за горячей клавиши |

## Горячие клавиши

Глобальные сочетания работают и когда окно кликера свёрнуто. Для кликов в окно,
запущенное от администратора, кликеру нужны такие же права.

| Клавиши | Действие |
|---|---|
| выбранная в окне | включить / выключить клики |
| `Ctrl+Alt+F8` | запомнить текущую позицию курсора как точку клика |
| `Ctrl+Alt+F10` | выйти |

Клавишу старт/стоп можно выбрать в выпадающем списке окна: `Ctrl+Alt+F3` (по умолчанию),
`Ctrl+Alt+Space`, `Ctrl+Shift+F3`, `Alt+Insert`. Выбор ложится в
`%APPDATA%\autoclicker\hotkey.txt` и действует и в консольном режиме. Смысл именно в выборе:
`F3` на ноутбуках и игровых клавиатурах часто живёт только вместе с `Fn`, а варианты без
функционного ряда от этого не зависят. Если новое сочетание занято, прежняя рабочая
клавиша остаётся активной, а выбор не сохраняется.

Если клавиши молчат, кликер пишет причину в нижней строке окна (после старта окно свёрнуто —
верните его кликом по значку в трее):

- «Горячие клавиши заняты» — комбинацию не удалось зарегистрировать, её держит другое
  приложение или первое окно кликера;
- «Окно от администратора активно: клики не доходят» — активное окно требует тех же прав:
  запустите `autoclicker.exe` тоже от администратора.

Работать без клавиатуры позволяет меню значка в трее (правый клик): «Старт/Стоп»,
«Взять позицию курсора», «Выход». Само меню доходит всегда — его отдаёт шелл, а не активное окно,
так что оно выручает и когда клавиши заняты, и когда нужная клавиша живёт только с `Fn`. Но
нажатие в меню только включает кликер: в окно от администратора эти клики по-прежнему не приходят.
Кнопка «Взять позицию курсора» в окне и в тре даёт три секунды поставить курсор в нужную точку —
иначе запомнился бы сам клик по кнопке.

## Сборка

Нужен .NET 10 SDK и Windows x64. Одна команда собирает ровно один переносимый файл:

```powershell
dotnet publish -c Release
```

Результат — `dist\autoclicker.exe` (~51 МБ: код плюс .NET-рантайм, сжатые в один файл).
Все настройки single-file сборки лежат в `autoclicker.csproj`, флаги добавлять не нужно.

## Консольный режим

Без аргументов открывается окно. С аргументами кликер работает из консоли:

```powershell
.\autoclicker.exe --interval 100 --count 10
.\autoclicker.exe --button right --x 640 --y 480
.\autoclicker.exe --interval 500            # ждёт выбранную клавишу, старт по ней
```

| Аргумент | Значение |
|---|---|
| `--interval <мс>` | пауза между кликами, по умолчанию 500, минимум 10 |
| `--button <имя>` | `left` (по умолчанию), `right`, `middle` |
| `--count <n>` | сколько кликов сделать; `0` — без лимита |
| `--x <пикс>` / `--y <пикс>` | фиксированная точка вместо позиции курсора |
| `--help` | список аргументов |

## Ограничения

- **Окна с правами выше.** Если игра или программа запущены от администратора, клики от
  обычного кликера до неё не дойдут (защита UIPI). Запустите `autoclicker.exe` тоже от
  администратора — окно подскажет о разнице прав. Это ограничение кликов, а не диагностика
  доставки горячих клавиш.
- **Античиты.** Онлайн-игры такие вводы отклоняют или наказывают за них. Утилита
  рассчитана на свои приложения, тесты и одиночные игры.
- **Курсор.** Клик идёт туда, где курсор. Если оставить его на окне кликера, собственный
  клик попадёт в его же кнопку — такие клики помечены в `dwExtraInfo` и кнопкой игнорируются,
  а живой клик останавливает всегда. Уберите курсор с окна, иначе кликер кликает в себя.
